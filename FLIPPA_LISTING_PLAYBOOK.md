## 🤝 PART 2: BUYER HANDOVER GUIDE
*Give this section to the buyer after they purchase the app.*

Welcome to ShopieSpy! Here is your step-by-step guide to taking full ownership of your new SaaS.

### **1. Vercel & GitHub Transfer**
- Accept the GitHub repository transfer link sent to your email.
- Create a free account on [Vercel](https://vercel.com).
- Click "Add New Project" and import the ShopieSpy GitHub repository.

### **2. Supabase (Database) Setup**
- Create a free account on [Supabase](https://supabase.com).
- We will invite you as an Owner to the existing Supabase project, OR you can create a new project and we will provide the SQL migration file to instantly clone the database structure.

### **3. Setting up Payments (Going Live)**
ShopieSpy is currently configured with Stripe/PayPal Sandbox (Test Mode) so you can safely test the checkout flow. To start receiving real money:
1. Create a [Stripe](https://stripe.com) account.
2. Go to Developers > API Keys and copy your **Live Publishable Key** and **Live Secret Key**.
3. Go to your Vercel Dashboard > Settings > Environment Variables.
4. Update the `STRIPE_SECRET_KEY` and `NEXT_PUBLIC_STRIPE_KEY` with your Live keys.
5. Click **Redeploy** on Vercel. You are now ready to accept real payments!

### **4. Setting up AI (Gemini)**
1. Go to Google AI Studio and generate a free API key.
2. Add the key to Vercel as `GEMINI_API_KEY` and redeploy.
